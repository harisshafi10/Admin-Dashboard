# Dev Admin Dashboard

A modern admin dashboard built with React and Tailwind CSS.

## Features
- Dashboard analytics (cards + charts)
- User management (CRUD)
- Search & sorting
- Responsive layout

## Tech Stack
- React
- Tailwind CSS
- Recharts
